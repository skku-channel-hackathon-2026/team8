# 타공사 테스트 케이스

화면이 서버를 통해 돌기 시작했습니다. 여기 적힌 것은 **두 사람 이상이 얽힐 때
비로소 확인되는 것들**입니다. 혼자 눌러 보는 것만으로는 드러나지 않습니다.

`[자동]`은 `pnpm test`와 `scripts/` 스크립트가 이미 확인합니다. 표시가 없는
것은 사람이 눌러 봐야 합니다.

## 준비

터미널 두 개:

```sh
corepack pnpm dev:cloudflare
```

```sh
corepack pnpm dev:wam
```

데모 데이터를 채웁니다. 두 번 돌려도 안전합니다.

```sh
node scripts/seed-demo.mjs --for me
```

창을 세 개 엽니다. **`?as=` 값 하나가 계정 하나입니다.**

| 창  | 주소                                     | 누구                                     |
| --- | ---------------------------------------- | ---------------------------------------- |
| A   | `http://localhost:5173/?as=demo-sunbae1` | 김선배 (헌내기)                          |
| B   | `http://localhost:5173/?as=demo-sinip1`  | 박새내 (새내기, 3단계까지 완료)          |
| C   | `http://localhost:5173/?as=me`           | 새로 가입할 나 (**새내기로 가입**하세요) |

처음부터 다시 하려면:

```sh
corepack pnpm exec wrangler d1 execute DB --local --command="DELETE FROM app_records"
```

> 한 창에서 한 일이 다른 창에 보이기까지 **최대 3초**입니다. 바로 안 보인다고
> 실패로 적지 마세요. 5초를 세고 판단합니다.

## 아직 안 되는 것

정직하게 적어 둡니다.

- **사진 인증**: 인증에 붙인 사진은 서버로 올라가지 않습니다. 글만 전달됩니다.
- **AI 시간표 인식**: 배포 서버에 `ANTHROPIC_API_KEY`가 없습니다.
  `curl <배포주소>/api/ready` → `{"ok":true,"ai":false}`. 운영진에게 키 등록을
  요청해야 켜집니다. 그때까지는 "직접 입력"으로 시연하세요.
- **실시간 푸시**: 3초마다 다시 받아오는 방식입니다. 즉시가 아닙니다.
- **자정을 넘는 마감**: 마감 시각은 하루 안에서만 고릅니다.
- **Desk 안에서의 검증**: 위 표는 브라우저 기준입니다. WAM 높이(660) 잘림,
  글꼴 로딩, 채널톡이 `sessionToken`을 실제로 주는지는 **공통 해커톤 채널에서
  따로 확인해야 합니다.**
